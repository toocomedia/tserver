Developer Integration Recipes

Because ai-helper.js is loaded globally in layout.html, you can add AI capabilities to any page or wizard with simple HTML attributes or 1-line JS calls.

1. Pre-filled "Ask AI" Button

Add data-ai-prompt to any button or link to open the drawer with a pre-filled question:

<button type="button" class="btn btn--secondary btn--sm" 
        data-ai-prompt="Explain how to configure environment variables for Node.js.">
  <i data-lucide="sparkles"></i> Ask AI
</button>

2. "Explain Error" Button for Logs

Add data-ai-explain-error pointing to a log container ID:

<button type="button" class="btn btn--danger btn--sm" 
        data-ai-explain-error="#deployment-live-logs"
        data-ai-context="Apps Engine Deployment Failure">
  <i data-lucide="sparkles"></i> Explain Error with AI
</button>

3. Programmatic Call from JavaScript

AiHelper.open({
  title: "App Setup Assistant",
  context: "Configuring App: my-flask-app | Repo: github.com/user/repo",
  initialPrompt: "What environment variables and port does this Flask app need?"
});

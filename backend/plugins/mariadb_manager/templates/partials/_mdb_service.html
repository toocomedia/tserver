MariaDB Service Specifications
Service Status
MariaDB Engine Active
Plugin Version
MariaDB Manager v{{ plugin_version }}
Listening Address
127.0.0.1:3306 (Loopback only)
UNIX Socket
/run/mysqld/mysqld.sock
Default Storage Engine
InnoDB
Default Character Set
utf8mb4 / utf8mb4_unicode_ci
CLI & Application Connection Snippets
CLI (mysql)
mysql -h 127.0.0.1 -u [username] -p [database]
PHP PDO (MySQL)
$pdo = new PDO('mysql:host=127.0.0.1;port=3306;dbname=[database]', $user, $password);
Node.js (mysql2)
mysql://[user]:[password]@127.0.0.1:3306/[database]
Python (PyMySQL)
mysql+pymysql://[user]:[password]@127.0.0.1:3306/[database]
User Isolation Architecture
Grant Isolation
Each restricted user is granted privileges strictly on their dedicated database (GRANT ALL ON db.*)
Host Restriction
Scoped strictly to localhost (127.0.0.1) TCP and local UNIX socket
Administrative Access
Root access is locked to system UNIX socket authentication only

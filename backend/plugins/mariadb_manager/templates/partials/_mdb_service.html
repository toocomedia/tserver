CLI & Application Connection Snippets
CLI (mysql)
mysql -h 127.0.0.1 -u [username] -p [database]
PHP PDO (MySQL)
$pdo = new PDO('mysql:host=127.0.0.1;port=3306;dbname=[database]', $user, $password);
Node.js (mysql2)
mysql://[user]:[password]@127.0.0.1:3306/[database]
Python (PyMySQL)
mysql+pymysql://[user]:[password]@127.0.0.1:3306/[database]
